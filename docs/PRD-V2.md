## 2. 产品目标

| #  | 目标            | 说明                                                                          |
|----|---------------|-----------------------------------------------------------------------------|
| G1 | **视觉一致性**     | 统一所有页面（5 个游戏 + 5 个随机工具 + 通用页面）的视觉语言：圆角、配色、导航栏、间距、字体层级，消除当前"拼凑感"，打造完整的产品视觉体验 |
| G2 | **AI 增强游戏体验** | 以 AI 主持人的角色融入游戏流程，为不同类型游戏设计差异化的 AI 交互方式（推理裁决、画作品评、发言引导等），降低玩家学习成本、提升游戏趣味性   |
| G3 | **扩展随机工具矩阵**  | 新增"答案之书"工具（唯一实例），丰富随机工具的趣味性和社交属性，为用户提供更多桌游辅助决策手段                            |

## 5. UI 设计要求

### 5.1 设计系统（Design System）更新

| 组件类别                 | 当前问题                      | 设计要求                                                                                                 |
|----------------------|---------------------------|------------------------------------------------------------------------------------------------------|
| **圆角（CornerRadius）** | 全部为 `0.dp`，无圆角            | 按组件类型分级：`card: 16.dp`, `button: 12.dp`, `dialog: 20.dp`, `input: 10.dp`, `chip: 8.dp`, `xxxl: 28.dp` |
| **首页 GameCard 配色**   | 5 个游戏卡片使用相同金黄色渐变          | 每个游戏分配独立主题色：卧底(紫)、阿瓦隆(蓝)、你画我猜(橙)、猎巫镇(深红)、一夜狼人(墨绿)                                                    |
| **顶部导航栏**            | 部分页面有 `CommonTopBar`，部分没有 | 所有二级页面统一使用 `CommonTopBar`，包含：返回按钮 + 标题 + 可选右侧操作按钮                                                    |
| **页面背景色**            | 部分页面用硬编码颜色                | 统一使用 `MaterialTheme.colorScheme.background` / `surface`                                              |
| **间距系统**             | 不同页面间距不一致                 | 所有页面使用 `LocalAppDesign.current.spacing` 统一间距                                                         |

### 5.2 首页布局

- 底部 Tab 保持不变：首页 / 随机工具 / 信息 / 设置
- 首页 GameCard：展开式卡片，每个游戏有独立主题色渐变背景
- GameCard 图标 + 游戏名称 + 简短描述 + 支持人数标签 + 模式选择（单手机/同网络/跨网络）

### 5.3 随机工具页面

- 顶部：横向滚动的工具配置列表（圆形图标 + 名称标签）
- 中部：内容区域（根据工具类型展示不同组件）
- 底部（仅卡牌类型）：一键翻转按钮
- **新增**：答案之书入口图标（书本样式图标）

### 5.4 答案之书页面设计

- **入口**：随机工具配置列表中的独立图标（书本图标），不可删除、不可编辑
- **交互流程**：
    1. 用户点击答案之书图标 → 显示答案之书界面
    2. 界面展示一本合上的书的视觉
    3. 用户输入问题（可选）→ 点击"翻开答案之书"
    4. 翻书动画 → 显示随机答案
    5. 可重新翻开获取新答案
- **唯一性**：答案之书为系统内置，只有一份配置，不可新增/删除

### 5.5 AI 交互设计

- **交互形式**：AI 评论以气泡卡片形式嵌入游戏流程，不阻断游戏进行
- **触发时机**：按游戏阶段自动触发（发言前 → AI 引导；投票后 → AI 裁决）
- **降级策略**：AI 不可用时，显示本地预设的固定文案，不阻塞游戏流程
- **视觉标识**：AI 消息带有机器人图标标识，与玩家消息区分
