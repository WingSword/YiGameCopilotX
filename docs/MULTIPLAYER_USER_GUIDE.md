# 联机使用说明

网络房间的房主可在「管理员模式 → 邀请玩家 · 二维码」显示邀请，Android、Harmony 和网页均支持。成员用相机或浏览器识别后打开网页版，填写昵称加入。手机发布版默认服务地址保持原值；上线二维码前需部署网页版并配置服务端 `PUBLIC_WEB_URL`，详见 [网页部署说明](WEB_AND_SIX_CLOUD_GAMES.md)。

房主仍然参赛，只切换玩家界面和管理界面。每次切换向房间成员提示，顶部持续显示当前模式；个人身份和行动在玩家模式完成，管理员模式负责推进游戏与管理房间。

## 局域网联机

局域网联机适合聚会、宿舍、同一个 Wi-Fi 或同一路由器下的玩家。创建房间的设备会作为主机，其他玩家通过局域网搜索并加入。

1. 房主进入「联机」Tab，选择「局域网」。
2. 点击「创建房间」，填写房间名、昵称、游戏类型、最大玩家数和可选密码。
3. 房主创建成功后停留在房间大厅，并保持 App 在前台。
4. 其他玩家进入「联机」Tab，选择「局域网」，点击「搜索房间」。
5. 搜索到房间后点击房间卡片，输入昵称和密码后加入。
6. 房主确认人数后点击「开始游戏」。

注意事项：

- 当前 Android 端是主要支持路径，可创建主机房间、搜索并加入局域网房间。
- iOS 端局域网发现已有基础代码，但主机广播/单播仍需继续适配；Web/Wasm 端当前不支持局域网 Socket 主机能力。
- 所有设备需要处在同一个局域网内。
- 如果搜索不到房间，先确认房主和玩家连接的是同一个 Wi-Fi，并关闭可能隔离局域网设备的访客网络。
- 房主设备关闭 App、切后台过久或断网时，房间会关闭，其他玩家需要重新加入新房间。
- 设置密码的房间会在加入时校验密码，人数达到上限后不允许继续加入。

## 网络房间联机

网络房间适合不在同一局域网的玩家，通过在线房间服务创建或加入房间。

1. 进入「联机」，原生端选择「网络房间」，Web 直接显示网络入口。
2. 房主填写昵称、游戏类型和人数，密钥可自填或自动生成，再创建房间。六位房间号由服务分配。
3. 其他玩家使用同一服务器，填写昵称、房间号和密钥加入。
4. 玩家准备后由房主开始。狼人、猎巫镇、阿瓦隆、你画我猜需配置人数到齐；记账至少两人。
5. 身份游戏先私下查看自己的牌并确认，再根据页面提示行动。房主也不能查看其他人的秘密身份。

注意事项：

- 六种网络玩法为谁是卧底、一夜终极狼人、猎巫镇简化版、桌游记账、阿瓦隆和你画我猜。各游戏的夜间行动、任务、答案、计时、投票和积分由 Java 服务处理。
- 房间通过 HTTP JSON 同步，界面以服务返回的结果为准。网络中断后可以重试；记账与绘画的待确认操作会保留，避免重复扣款或加分。
- 房间号和密钥需要由房主告知其他玩家。
- Android/Harmony 默认服务器仍为 `http://8.133.216.39:8080`，本机测试可填写自定义地址。HTTPS Web 应通过同一网站的 API 代理访问服务，详见[Web 部署说明](WEB_AND_SIX_CLOUD_GAMES.md)。
- 关闭重开后，从「联机 → 返回已加入的房间」恢复成员；主动离开会撤销该身份，进行中的规则游戏会中止。Web 使用浏览器本地存储保存成员令牌，清理网站数据或更换浏览器会影响恢复。
- 若连接失败，请检查网络可用性，稍后重试或改用局域网联机。

## App 入口调整

底部导航为「首页」「工具」「联机」「我的」：

- 「首页」用于选择游戏和本地开局。
- 「工具」用于骰子、转盘、答案之书等随机工具。
- 「联机」集中管理局域网房间和网络房间。
- 「我的」用于主题、AI、对局统计等配置和记录。
