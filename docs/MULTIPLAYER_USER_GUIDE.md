# 联机使用说明

## 局域网联机

局域网联机适合聚会、宿舍、同一个 Wi-Fi 或同一路由器下的玩家。创建房间的设备会作为主机，其他玩家通过局域网搜索并加入。

1. 房主进入「联机」Tab，选择「局域网」。
2. 点击「创建房间」，填写房间名、昵称、游戏类型、最大玩家数和可选密码。
3. 房主创建成功后停留在房间大厅，并保持 App 在前台。
4. 其他玩家进入「联机」Tab，选择「局域网」，点击「搜索房间」。
5. 搜索到房间后点击房间卡片，输入昵称和密码后加入。
6. 房主确认人数后点击「开始游戏」。

注意事项：

- 当前 Android 端是主要支持路径，可创建主机房间、搜索并加入局域网房间。
- iOS 端局域网发现已有基础代码，但主机广播/单播仍需继续适配；Web/Wasm 端当前不支持局域网 Socket 主机能力。
- 所有设备需要处在同一个局域网内。
- 如果搜索不到房间，先确认房主和玩家连接的是同一个 Wi-Fi，并关闭可能隔离局域网设备的访客网络。
- 房主设备关闭 App、切后台过久或断网时，房间会关闭，其他玩家需要重新加入新房间。
- 设置密码的房间会在加入时校验密码，人数达到上限后不允许继续加入。

## 网络房间联机

网络房间适合不在同一局域网的玩家，通过在线房间服务创建或加入房间。

1. 进入「联机」Tab，选择「网络房间」。
2. 房主填写房间号和房间密钥，点击「创建」。
3. 其他玩家填写相同房间号和密钥，点击「加入」。
4. 进入网络房间后由房主开始游戏。

注意事项：

- 网络房间依赖在线房间服务和 WebSocket 连接。
- 点击创建/加入后，App 会先确认 WebSocket 可连接且消息已发送；服务端最终房间状态以房间页收到的同步数据为准。
- 房间号和密钥需要由房主告知其他玩家。
- 若连接失败，请检查网络可用性，稍后重试或改用局域网联机。

## App 入口调整

底部 AppTab 当前为「首页」「工具」「联机」「设置」：

- 「首页」用于选择游戏和本地开局。
- 「工具」用于骰子、转盘、答案之书等随机工具。
- 「联机」集中管理局域网房间和网络房间。
- 「设置」用于主题、AI 等配置。
