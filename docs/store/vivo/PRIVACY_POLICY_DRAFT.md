## 一、我们处理哪些信息

### 本机功能

为提供桌游流程、随机工具、统计与虚拟账本，我们在应用存储或运行内存中保存您输入的玩家显示名称、工具选项、词库、游戏配置、对局记录及虚拟账目。本机功能本身不将这些记录提交给云房间服务器。若您主动导出、复制或分享信息，接收方会获得您选择的内容。Android 的系统备份和设备迁移也可能处理应用数据，具体取决于设备设置。

### 网络房间

您创建或加入房间时，服务器处理昵称、房间号、随机成员标识和会话认证信息，用于区分房间成员、恢复连接及校验操作权限。随机成员标识并非 IMEI、Android ID 等硬件永久标识。

为完成您选择的游戏，我们处理成员准备与在线状态、角色身份、行动、投票、对局结果；你画我猜还处理绘画轨迹、题目与猜词输入；云账本还处理玩家显示名称、虚拟余额、交易及备注。相关内容会在服务器保存并按规则同步。公开对局信息对同房成员可见，角色等私密信息按玩法阶段下发，结算阶段可能公开。房主切换管理界面时向成员显示提醒。

客户端保存房间会话及需要重试的操作，用于恢复连接和避免重复提交。任何网络连接都会涉及 IP 地址等网络信息；服务端使用连接地址进行限流和异常请求控制。服务器基础设施及日志的具体处理范围见第五节。

### 局域网功能

您主动使用局域网功能时，应用发现同一网络中的房间并向参与设备传送房间与对局信息。网络地址用于建立连接。请仅向您希望共同游戏的人分享房间信息。

### 可选 AI 提示

AI 提示可以使用本地预设。本地预设不向第三方 AI 服务提交请求。如果您主动启用 DeepSeek 并填写自己的 API Key，应用将请求所需的游戏上下文、提示内容和 API 认证信息发送给该服务，以获取回复。API Key 保存在应用配置中。您可以关闭该功能或清空密钥，不影响基础桌游与随机工具。发布前应提供第三方服务的独立说明和选择入口；第三方运营主体、政策链接及其保留规则【待确认并补齐】。
