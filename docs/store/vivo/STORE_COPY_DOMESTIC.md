# 国内商店版文案草稿

适用渠道：Android `domestic` / Harmony 国内商店版。与完整版分开提交，尚未取得平台审核结论。

## 简介

聚会桌游与随机工具助手。

桌游助手为线下聚会提供同机身份发放、主持流程、随机选择和虚拟积分记账。

- 同机桌游：提供谁是卧底、一夜终极狼人、阿瓦隆、你画我猜和猎巫镇的流程辅助。按提示传递手机查看身份；猎巫镇需额外一位不参赛主持人。
- 随机工具：转盘、抽签、随机数、硬币、骰子、答案之书等，可自定义选项。
- 本机记账：记录虚拟游戏币、积分和筹码，支持批量收付、交易历史和撤销。不提供真实资金充值、提现或支付。
- 个人记录：查看对局统计、调整外观，按需配置可选的对局提示。

此发行版不提供网络房间、局域网房间、云端账本或扫码加入。

## 更新说明

国内商店版保留同机游玩及本地工具，关闭多设备联机入口与会话恢复。优化首页入口、随机工具栏、同机传递提示和本机记账交互。

## 审核路径与说明

无需注册。首页展开游戏，点击开始并按人数配置；同机身份玩法按编号依次传递设备。账本在「我的 → 桌游记账」，随机工具在「工具」。AI 对局提示为可选项，用户自行配置第三方 API 后才请求外部服务；未配置不影响核心玩法。不能把此包表述为完全无网络请求。

Android 包名为 `org.walks.gamecopilot.domestic`，须与最终签名包、公钥材料及后台记录一致。正式提审前仍需补齐真实运营者资料、隐私政策和平台要求的资质；本文件不替代审核。
